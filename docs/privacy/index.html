어린이와 보호자에게

꼬마 시장은 물건을 고르고 놀이돈으로 거스름돈을 연습하는 Android 앱입니다. 이름, 학교, 이메일 주소를 입력하거나 회원가입할 필요가 없습니다. 실제 결제와 광고가 없고, 개발자는 앱으로 이용자의 행동을 추적하거나 놀이 기록을 수집·공유하지 않습니다.

첫 출시판의 예시 상품 12개

Google Play용 첫 출시판(버전 코드 3)은 앱 안에 들어 있는 예시 상품 12개를 사용합니다. 인터넷이 켜져 있어도 앱을 열거나 상품 목록을 다시 보거나 계산할 때 상품 서버에 접속하지 않습니다. 이 방침도 앱 안에서 인터넷 없이 읽을 수 있습니다.

앱은 위치, 사진, 연락처, 광고 식별자를 수집하거나 전송하지 않습니다. TalkBack 버튼은 기기의 Android 접근성 설정을 엽니다.

장바구니와 영수증

고른 물건과 수량, 놀이돈, 거스름돈 답, 영수증은 놀이 중 기기 메모리에만 둡니다. 영수증에서 “다시 장보기”를 누르거나 앱을 완전히 종료하면 이전 놀이 기록은 사라집니다.

상품 서버를 사용하던 버전의 접속 기록

이전 내부 테스트판(버전 코드 2)이나 상품 서버를 사용하는 검사판에서 온라인으로 앱을 열거나 목록을 다시 불러오면, 예시 상품을 받기 위해 Supabase Pte. Ltd.에 HTTPS 요청이 전송됩니다. 이 버전에서 상품 서버 접속을 원하지 않으면 앱을 열기 전에 인터넷을 끄고 기기에 들어 있는 상품으로 놀 수 있습니다.

이 요청에는 접속 IP 주소가 전달됩니다. 접속 기록에는 시각, 요청 경로와 결과, 접속 프로그램과 통신망 정보, IP로 추정한 국가·지역·도시 등이 포함될 수 있습니다. 상품 DB는 싱가포르에 있으며, Supabase는 서비스 운영과 보안을 위한 로그를 유럽연합(EU)의 데이터센터에서 처리·보관한다고 안내합니다.

개발자가 조회할 수 있는 기본 상품 API 로그의 보관 기간은 무료 요금제 기준 1일입니다. 이 기간은 공급자의 모든 내부 보안 기록이 삭제되는 시점을 뜻하지 않습니다. 개발자는 이 기록을 어린이별 놀이 내역으로 만들거나 광고에 이용하지 않습니다. 공급자 개인정보 문의처는 privacy@supabase.com입니다.
