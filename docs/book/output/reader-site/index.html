Windows에서 첫 예제 실행하기

  1. 책 2장을 따라 Node.js와 Git Bash를 준비합니다. 파일 탐색기의 다운로드 폴더에서 market-lab.zip을 마우스 오른쪽으로 클릭해 압축 풀기를 선택합니다.
  2. 내 Windows 사용자 폴더 아래에 market-book 폴더를 만들고 그 안의 kit에 풉니다. kit을 열었을 때 start.mjs, index.json, objects가 보이면 준비가 끝났습니다.
  3. 시작 메뉴에서 Git Bash를 열고 다음 명령을 한 줄씩 입력한 뒤 Enter를 누릅니다. 
    cd ~/market-book/kit
node start.mjs 03
cd work/ch03
node checkout.mts

    총 3개 / 5,500원이 나오면 성공입니다. ~는 내 사용자 폴더를 뜻합니다. 다른 장도 kit에서 원하는 장 번호를 넣어 준비합니다.

VS Code에서 명령어 도움말 열기

압축을 푼 뒤 start.mjs가 있는 폴더를 VS Code에서 여세요. F1 → 작업: 작업 실행 → 실습 명령어 도움말을 선택하면 1~20장의 제목과 여는 명령을 터미널에서 함께 볼 수 있습니다. 직접 node start.mjs --help를 입력해도 됩니다.

작업 목록의 한 장의 실습 파일 열기에서 장 제목을 고르세요. 전체 장의 실습 파일 한 번에 열기를 선택하면 왼쪽 탐색기의 work 폴더에 20개 장이 준비되고, 현재 창에 장별 대표 파일 20개가 열립니다. 터미널에서는 다음 명령 중 하나를 입력하세요.

  • 6장 파일 열기 node start.mjs --open 06
  • 20장 완성본 열기 node start.mjs --open 20
  • 1~20장 전체 열기 node start.mjs --open all

20장 완성본에서 50,000원으로 장보기

위에서 받은 장별 ZIP을 새 폴더에 풀고 start.mjs가 있는 위치에서 node start.mjs 20을 입력합니다. VS Code에서 work/ch20/apps/mobile을 열고 PowerShell 터미널에서 npm.cmd ci, npm.cmd run web을 실행합니다.

이전 장별 ZIP으로 작업했다면 50,000원이 포함된 20장 완성 소스를 별도 폴더에 풉니다. 압축 속 저장소 폴더에서 apps/mobile을 열어 같은 npm 명령을 실행합니다.

11~13장의 데이터 찾기

가격표에는 책의 계산을 재현하기 위해 정한 예시 금액이 들어 있습니다. 사과 2개와 우유 1팩을 담으면 1,500 × 2 + 2,500 = 5,500원입니다.

11장 앱의 상품 목록과 데이터베이스 초기 파일

Git Bash에서 cd ~/market-book/kit, node start.mjs 11을 차례로 실행합니다. VS Code에서 work/ch11 폴더를 열어 다음 파일을 확인하세요.

  • 앱에서 읽는 예시 상품과 가격은 apps/mobile/src/data/sample-products.ts에 있습니다.
  • 데이터베이스에 예시 상품과 가격을 채우는 파일은 supabase/seed.sql입니다. 테이블을 만드는 SQL 파일은 supabase/migrations/에 있습니다.
