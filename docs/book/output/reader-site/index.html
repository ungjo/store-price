Windows에서 첫 예제 실행하기

  1. 책 2장을 따라 Node.js와 VS Code를 준비합니다. 위의 장별 실습 예제 ZIP 받기를 누르고 Windows 파일 탐색기에서 다운로드 폴더를 엽니다.
  2. 압축을 풀 위치를 정합니다. 책에서 kit은 압축을 풀어 예제 파일을 담아 둔 폴더를 가리킵니다. market-lab.zip을 마우스 오른쪽 버튼으로 눌러 압축 풀기를 선택한 뒤, 제시된 폴더에 그대로 풀어도 됩니다. 이미 다운로드 → market-lab (1)에 풀었다면 그 이름 그대로 다음 단계로 가세요.
    책과 같은 이름으로 kit 폴더를 만들려면

    Windows 파일 탐색기 주소창에 %USERPROFILE%을 입력하고 Enter를 누르면 내 사용자 폴더가 열립니다. 여기에 새 폴더로 market-book을 만들고, 그 안에 kit을 만듭니다. ZIP의 압축 풀기 창에서 찾아보기를 눌러 방금 만든 kit을 선택한 뒤 압축을 풉니다.

    예를 들어 Windows 사용자 이름이 minji라면 C:\Users\minji\market-book\kit입니다. 책의 Git Bash 명령에서 ~/market-book/kit은 이 위치를 뜻합니다.

  3. 실제 파일이 보이는 폴더를 엽니다. 압축을 푼 폴더에서 start.mjs, index.json, objects가 나란히 보이는지 확인하세요. 안에 market-lab 같은 하위 폴더 하나만 보이면 한 단계 더 들어가세요. VS Code의 파일 → 폴더 열기에서 세 항목이 보인 바로 그 폴더를 선택합니다.
  4. 3장 예제를 실행합니다. VS Code 위쪽의 터미널 → 새 터미널을 누릅니다. 아래쪽에 열린 입력 칸에 다음 명령을 한 줄씩 입력하고 Enter를 누르세요. 
    node start.mjs 03
cd work/ch03
node checkout.mts

    마지막 줄에 총 3개 / 5,500원이 보이면 성공입니다. 같은 터미널에서 다른 장을 꺼낼 때는 먼저 cd ../..를 입력합니다. 그러면 work/ch03에서 start.mjs가 있는 폴더로 돌아옵니다.

VS Code에서 명령어 도움말 열기

압축을 푼 뒤 start.mjs가 있는 폴더를 VS Code에서 여세요. F1 → 작업: 작업 실행 → 실습 명령어 도움말을 선택하면 1~20장의 제목과 여는 명령을 터미널에서 함께 볼 수 있습니다. 직접 node start.mjs --help를 입력해도 됩니다.

작업 목록의 한 장의 실습 파일 열기에서 장 제목을 고르세요. 전체 장의 실습 파일 한 번에 열기를 선택하면 왼쪽 탐색기의 work 폴더에 20개 장이 준비되고, 현재 창에 장별 대표 파일 20개가 열립니다. 터미널에서는 다음 명령 중 하나를 입력하세요.

  • 6장 파일 열기 node start.mjs --open 06
  • 20장 완성본 열기 node start.mjs --open 20
  • 1~20장 전체 열기 node start.mjs --open all
