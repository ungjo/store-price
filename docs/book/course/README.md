# 꼬마 시장 실습 예제

먼저 ZIP을 모두 풉니다. Windows에서 `start.mjs`와 `index.json`, `objects`가 같은 폴더에 있어야 합니다. 이 폴더를 책에서는 `~/market-book/kit`이라고 부릅니다. Node.js 26과 Git Bash를 사용합니다.

~~~bash
cd ~/market-book/kit
node start.mjs 06
cd work/ch06/apps/mobile
npm ci
npm start
~~~

첫 npm 설치에는 인터넷 연결이 필요합니다. `node start.mjs 번호` 자체는 연결 없이 동작합니다. 장 번호 03~20 중 하나를 고르세요. 결과는 `work/ch번호`의 독립된 폴더에 생성되며 기존 폴더를 덮어쓰지 않습니다. `objects`에 같은 파일 한 벌만 두어 여러 장에 같은 이미지와 패키지 잠금 파일을 반복 저장하지 않았습니다. 도구가 내용을 확인해 정상적인 파일명과 폴더 구조로 복원합니다.

| 장 | 참고 코드의 역할 |
| --- | --- |
| 03 | 두 모듈 계산 예제. work/ch03에서 `node checkout.mts` |
| 04 | `adcfaab`의 SDK 58 첫 앱. 네이티브·웹 예시 6개. 4장 중간에 작성할 작은 화면 코드는 본문에 수록 |
| 05~10 | 각 장까지 반영된 교육용 앱. 상품 분류 → 장바구니 → 예산 → 지불 → 퀴즈 → 영수증 |
| 11~14 | `479f6f5`의 12개 상품 기준 앱과 DB. 같은 코드에서 SQL·HTTP·미리보기·오프라인을 다른 실험으로 익힘 |
| 15 | `e15dac6`의 큰 글자·키보드 개선 |
| 16 | `c949154`의 TalkBack 개선 |
| 17 | `97b00ff`의 접근성 앱과 자동 검사 스크립트 |
| 18 | `807d295`의 브랜드 이미지와 검사 앱 설정 |
| 19 | `35b12e4`의 APK 실습 시작 소스. 19장대로 본인 계정과 패키지 설정을 적용 |
| 20 | `9f5fd13`의 완성본. 오늘의 놀이돈으로 10,000원이나 50,000원을 정하고, 낼 놀이돈으로 50,000원권까지 사용 |

16~19장에는 `3487654`의 Android용 **TalkBack 설정 열기** 버튼을 반영했고, 20장 완성본에도 같은 버튼이 있습니다. Android의 예시 상품 선택 화면, 장보기 화면 상단, 영수증 하단에서 기기 접근성 설정으로 이동해 TalkBack을 켜거나 끕니다. PC 브라우저에서는 이 버튼이 숨겨집니다.

**20장 완성본 열기.** 이 ZIP을 새 폴더에 푼 뒤 `start.mjs`가 보이는 폴더에서 `node start.mjs 20`을 입력합니다. VS Code의 **파일 → 폴더 열기**에서 `work/ch20/apps/mobile`을 열고 새 터미널에서 `npm.cmd ci`, `npm.cmd run web`을 차례로 입력합니다. 사과 2개와 우유 1팩을 담아 합계 5,500원을 만든 뒤 예산과 낼 돈을 각각 50,000원으로 선택하면 거스름돈 정답은 44,500원입니다.

이전 ZIP으로 만든 폴더에서 작업 중이라면 [20장 완성 소스 ZIP](https://github.com/ungjo/store-price/archive/9f5fd1318294b2bc5a7cfd700952f3512835febd.zip)을 별도 폴더에 풉니다. 압축을 풀어 나온 저장소 폴더 안의 `apps/mobile`을 VS Code에서 열고 같은 두 npm 명령을 실행합니다.

저장소 전체 이력이 필요한 비교·검사에서는 본문의 Git 복제 절차를 사용합니다. ZIP에서 생성한 폴더에는 Git 이력, 개인 `.env.local`, 계정 인증이나 서명 키가 포함되지 않습니다. 17장의 Git 보호 조건을 사용하는 독자는 그 장의 최초 커밋 안내를 따릅니다. 공개 예시를 원격에서 읽으려면 12장 절차대로 본인의 공개 연결값을 설정합니다. 내장 예시 놀이는 외부 가격 자료 없이도 가능합니다.

`steps/11`, `steps/13`, `steps/14`에는 메모리 DB와 지연 응답을 직접 실험하는 작은 파일이 있습니다. 선택한 장의 저장소 루트에서 `node ../../steps/11/catalog-query.mjs`와 같이 실행합니다. 11장의 DB 패키지 준비 순서를 먼저 따릅니다.

`practice/cart-total.ts`는 6.4절의 독립 계산 예제입니다. `node practice/cart-total.ts`의 결과는 총 3개에 5,500원입니다.
