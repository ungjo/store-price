# 꼬마 시장 실습 예제

먼저 ZIP을 모두 풉니다. Windows에서 `start.mjs`와 `index.json`, `objects`가 같은 폴더에 있어야 합니다. 이 폴더를 책에서는 `~/market-book/kit`이라고 부릅니다. Node.js 26을 설치하면 VS Code의 PowerShell 또는 Git Bash 터미널에서 도움말을 볼 수 있습니다.

## VS Code에서 명령어 도움말 열기

1. **파일 → 폴더 열기**에서 압축을 푼 뒤 `start.mjs`와 `index.json`이 보이는 폴더를 엽니다.
2. **F1**을 누르고 **작업 실행**을 입력한 뒤 **작업: 작업 실행**을 선택합니다. 위쪽에 새 목록이 열립니다.
3. **실습 명령어 도움말**을 선택합니다. 아래쪽 터미널에 1장부터 20장까지 제목과 각 장을 여는 명령, 전체 장을 한꺼번에 여는 명령, **20장 완성 앱을 PC 브라우저에서 실행**하는 순서가 나옵니다. 도움말을 보는 데는 인터넷 연결이나 패키지 설치가 필요하지 않습니다.

**작업: 작업 실행** 목록에서 **한 장의 실습 파일 열기**를 선택하면 번호와 제목을 보고 원하는 장을 고를 수 있습니다. **전체 장의 실습 파일 한 번에 열기**를 고르면 왼쪽 탐색기의 `work` 아래에 `ch01`부터 `ch20`까지 준비되고, 현재 VS Code 창에 각 장의 대표 파일이 하나씩 총 20개 열립니다. 같은 작업을 다시 실행해도 이미 수정한 실습 파일은 보존됩니다.

같은 작업을 **터미널 → 새 터미널**에서 명령으로 실행할 수도 있습니다.

| 원하는 작업 | 꾸러미 폴더에서 입력할 명령 |
| --- | --- |
| 모든 장의 열기 명령 보기 | `node start.mjs --help` |
| 6장 파일 열기 | `node start.mjs --open 06` |
| 20장 완성본의 소스 파일 열기 | `node start.mjs --open 20` |
| 1~20장 파일을 한 번에 열기 | `node start.mjs --open all` |
| 20장 앱을 PC 브라우저에서 다시 실행 (패키지 설치 후) | `npm.cmd --prefix ./work/ch20/apps/mobile run web` |
| 6장에서 실행할 명령 자세히 보기 | `node start.mjs --help 06` |

Git Bash에서는 `npm run help`, Windows PowerShell에서는 `npm.cmd run help`로도 전체 명령을 볼 수 있습니다.

새 ZIP에서 복원한 `work/ch20/apps/mobile`만 VS Code에서 열었다면 그 폴더의 새 터미널에서 `node ../../../../start.mjs --help 20`을 실행하세요. VS Code 작업이나 `npm run help`를 사용하려면 `start.mjs`가 있는 꾸러미 폴더를 엽니다. 새 ZIP은 별도 폴더에 풀면 이전에 작성한 실습 파일을 보존할 수 있습니다.

## 6장 실습 시작하기

Git Bash에서 책의 경로를 그대로 사용했다면 다음과 같이 실행합니다.

~~~bash
cd ~/market-book/kit
node start.mjs 06
cd work/ch06/apps/mobile
npm ci
npm start
~~~

첫 npm 설치에는 인터넷 연결이 필요합니다. `node start.mjs 번호` 자체는 연결 없이 동작합니다. 앱 개발 예제는 03~20장에서 고를 수 있고, 01장과 02장에서는 기획 활동지와 도구 점검표를 열 수 있습니다. 결과는 `work/ch번호`의 독립된 폴더에 생성되며 기존 폴더를 덮어쓰지 않습니다. `objects`에 같은 파일 한 벌만 두어 여러 장에 같은 이미지와 패키지 잠금 파일을 반복 저장하지 않았습니다. 도구가 내용을 확인해 정상적인 파일명과 폴더 구조로 복원합니다.

| 장 | 참고 코드의 역할 |
| --- | --- |
| 01 | 시장놀이 기획 활동지 `work/ch01/market-plan.md` |
| 02 | 개발 도구 점검표 `work/ch02/tool-checklist.md` |
| 03 | 두 모듈 계산 예제. work/ch03에서 `node checkout.mts` |
| 04 | `adcfaab`의 SDK 58 첫 앱. 네이티브·웹 예시 6개. 4장 중간에 작성할 작은 화면 코드는 본문에 수록 |
| 05~10 | 각 장까지 반영된 교육용 앱. 상품 분류 → 장바구니 → 예산 → 지불 → 퀴즈 → 영수증 |
| 11~14 | `479f6f5`의 12개 상품 기준 앱과 DB. 같은 코드에서 SQL·HTTP·미리보기·오프라인을 다른 실험으로 익힘 |
| 15 | `e15dac6`의 큰 글자·키보드 개선 |
| 16 | `c949154`의 TalkBack 개선 |
| 17 | `97b00ff`의 접근성 앱과 자동 검사 스크립트 |
| 18 | `807d295`의 브랜드 이미지와 검사 앱 설정 |
| 19 | `35b12e4`의 APK 실습 시작 소스. 19장대로 본인 계정과 패키지 설정을 적용 |
| 20 | `9f5fd13`의 완성본. 오늘의 놀이돈으로 10,000원이나 50,000원을 정하고, 낼 놀이돈으로 50,000원권까지 사용 |

16~19장에는 `3487654`의 Android용 **TalkBack 설정 열기** 버튼을 반영했고, 20장 완성본에도 같은 버튼이 있습니다. Android의 예시 상품 선택 화면, 장보기 화면 상단, 영수증 하단에서 기기 접근성 설정으로 이동해 TalkBack을 켜거나 끕니다. PC 브라우저에서는 이 버튼이 숨겨집니다. 16~20장의 PC 실습에서는 상품 화면이나 영수증이 열리면 키보드 초점이 새 화면 제목으로 이동합니다.

## 20장 완성 앱을 PC에서 실행하기 (본문 398쪽)

이전 ZIP으로 실습하고 있다면 [최신 장별 실습 예제 ZIP](https://ungjo.github.io/store-price/book/market-lab.zip)을 받으세요. ZIP을 **새 폴더**에 모두 풀고, VS Code의 **파일 → 폴더 열기**에서 `start.mjs`가 보이는 폴더를 엽니다.

**터미널 → 새 터미널**에서 PowerShell을 열고 한 줄씩 실행합니다. **같은 ZIP에서 이미 `work/ch20`을 만들었다면 둘째 줄부터** 시작하세요. 패키지를 처음 설치할 때는 PC를 인터넷에 연결하고, 설치가 끝나면 마지막 줄을 실행합니다.

~~~powershell
node start.mjs 20
cd work/ch20/apps/mobile
npm.cmd ci
npm.cmd run web
~~~

브라우저가 자동으로 열리지 않으면 터미널에 표시된 웹 주소를 여세요. 오늘의 놀이돈으로 50,000원을 고르고 사과 2개와 우유 1팩을 담으면 합계는 5,500원입니다. 50,000원권으로 지불하면 영수증의 거스름돈은 44,500원입니다.

저장소 전체 이력이 필요한 비교·검사에서는 본문의 Git 복제 절차를 사용합니다. ZIP에서 생성한 폴더에는 Git 이력, 개인 `.env.local`, 계정 인증이나 서명 키가 포함되지 않습니다. 17장의 Git 보호 조건을 사용하는 독자는 그 장의 최초 커밋 안내를 따릅니다. 공개 예시를 원격에서 읽으려면 12장 절차대로 본인의 공개 연결값을 설정합니다. 내장 예시 놀이는 외부 가격 자료 없이도 가능합니다.

`steps/11`, `steps/13`, `steps/14`에는 메모리 DB와 지연 응답을 직접 실험하는 작은 파일이 있습니다. 선택한 장의 저장소 루트에서 `node ../../steps/11/catalog-query.mjs`와 같이 실행합니다. 11장의 DB 패키지 준비 순서를 먼저 따릅니다.

`practice/cart-total.ts`는 6.4절의 독립 계산 예제입니다. `node practice/cart-total.ts`의 결과는 총 3개에 5,500원입니다.
