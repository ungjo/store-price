# 꼬마 시장 앱 개발 실습서 목차

작성일: 2026-11-22  
가제: **처음부터 따라 만드는 꼬마 시장 Android 앱**  
부제: **VS Code에서 첫 코드를 쓰고 내 Android 기기에 앱을 설치하기까지**

Windows PC와 Android 기기로 시장놀이 앱을 만들며 배우는 입문 실습서다. 프로그래밍을 처음 배우는 성인 독자도 파일을 만들고, 코드를 입력하고, 실행 결과를 확인하면서 따라갈 수 있도록 구성한다. 완성할 앱의 사용자는 초등학교 1~3학년이다. 앱 사용자와 책의 독자를 구분해 설명한다.

[전체 책 PDF](output/pdf/market-play-book.pdf) · [오프라인 HTML](output/market-play-book.html) · [장별 코드 ZIP](output/market-lab.zip) · [독자 자료실](https://ungjo.github.io/store-price/book/)

## 표지와 앞부분

### 표지 기획

- 제목: 처음부터 따라 만드는 꼬마 시장 Android 앱
- 부제: VS Code에서 첫 코드를 쓰고 내 Android 기기에 앱을 설치하기까지
- 중심 이미지: 현재 앱의 초록 장바구니·사과·빵 아이콘과 완성 앱의 상품 목록·영수증 화면.
- 색상 방향: 앱과 연결되는 초록색·크림색을 기본으로 사용.
- 표지 안내 문구: TypeScript · React Native · Expo 실습.
- 뒤표지: 독자가 만들 기능, 필요한 기본 환경, 단계별 소스코드 안내.
- 저자명과 예제 저장소 안내는 출판 시 확정한다. 실제 표지 이미지는 별도 제작한다.

**넣을 화면** — 설치 아이콘 → 상품 수량과 합계 → 거스름돈 정답 → 영수증 → 새 장바구니. 20.7절에서는 VS Code에서 예산과 지폐의 두 줄을 직접 수정하고, 브라우저에서 각각 50,000원 버튼이 생기는지 확인한 뒤 영수증과 대조한다.  
**독자 확인** — PC의 개발 서버와 연결되지 않은 Android 기기에서 처음부터 끝까지 장보기를 마친다.

JSON·YAML·TSX는 각각의 용도를 설명하고 일반 프로그래밍 언어와 구분한다. Java는 검사 도구 실행을 위해 도입하며 앱 화면 개발의 주 언어로 다루지 않는다. AI 도구는 작업 요청·오류 분석의 보조 수단으로 소개하되, 필수 코드는 책과 예제 소스로 제공한다.

현재 저장소의 기준은 Expo `~58.0.23`, React `19.3.0`, React Native `0.88.1`, TypeScript `~6.0.3`이다. 이는 이 프로젝트의 버전 기록이다. 실제 출판 실습 환경은 잠금 파일과 함께 재검증하고, 설치 안내에서 무조건 최신 버전을 사용하게 하지 않는다.

## 각 장의 공통 집필 형식

1. **이번 장에서 만들 결과:** 완성 화면과 배울 개념.
2. **시작 전 확인:** 필요한 프로그램, 계정, 파일과 이전 단계.
3. **한 단계씩 따라 하기:** 프로그램을 여는 위치, 선택할 항목, 실제 명령.
4. **파일별 코드:** 생성·수정할 경로, 붙여 넣을 위치, 실행 가능한 코드.
5. **처리 이유 설명:** 핵심 로직에 한국어 주석과 짧은 해설.
6. **실행 결과 확인:** 기대 화면, 입력 예시, 정확한 결과.
7. **막혔을 때 해결:** 실제 발생한 오류와 수정 과정.
8. **완료 점검:** 독자가 직접 수행할 검사와 장별 소스 기준.

첫 예제와 짧은 파일은 전체 코드를 제공한다. 긴 파일은 수정 위치와 완전한 변경 블록을 싣고, 같은 단계의 전체 파일을 예제 소스로 제공한다. 복사해서 실행해야 하는 핵심 코드 중간을 생략 기호로 대체하지 않는다.

프로그램 화면에는 그림 번호·설명·선택할 위치를 표시한다. 프로그램 화면은 독자가 파일을 열거나 버튼을 선택하는 순간에 싣고, 바로 다음에 확인할 앱 화면이나 터미널 출력을 붙인다. 계정 정보·토큰·인증서 비밀값·비공개 가격 원자료를 공개 예제나 화면에 포함하지 않는다.

중복되는 전체 소스와 긴 검사 로그는 저장소로 옮기고, 종이책에는 학습과 재현에 필요한 내용을 남긴다. 페이지를 줄일 때도 필수 설치 단계와 코드 입력 위치는 유지한다.

종이책 실습을 점검할 때는 독자가 직전 장의 완성 코드에서 시작해 본문의 변경만으로 다음 결과를 얻는지 확인한다. 예를 들어 새 5장의 상품 분류가 6장의 장바구니를 추가한 뒤에도 남아 있어야 한다. 장별 예제 소스도 이 순서로 맞춘다. 13·17장의 USB 승인, 19장의 첫 빌드와 APK 설치에는 PC와 기기 화면을 한 쌍으로 배치한다. 화면 글자가 인쇄 크기에서 작으면 여유 20쪽을 사용한다.
