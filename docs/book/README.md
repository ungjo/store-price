## 매 단계에 남길 기록

- 날짜와 목표
- 사용한 도구의 실제 버전
- 변경 파일과 선택한 이유
- 실제 실행 명령
- 실패한 부분과 해결 과정
- 실행한 검증 / 아직 하지 않은 검증
- 화면 캡처(개인정보·토큰 제외)
- 코드 기준 태그와 실제 커밋 ID
- 다음 장에서 풀 문제

각 장에는 해당 단계의 코드 커밋 ID를 기록합니다. 태그는 사용자가 실제로 만든 경우에만 기록합니다. 원고를 정리하는 커밋과 원고에서 설명하는 코드 커밋은 서로 다를 수 있으며, 실제 이력은 아래 명령으로 확인합니다.

```bash
git log --oneline --decorate
```

독자가 이전 장을 실행할 때 원래 작업 폴더를 변경하지 않으려면 별도 폴더에 저장소를 복제한 뒤 원하는 커밋 또는 사용자가 만든 태그를 체크아웃합니다. 패키지는 해당 장의 package-lock.json을 기준으로 npm ci로 설치합니다.

원고의 목표는 실제로 수행한 개발 과정을 재현하는 것입니다. 설치·테스트·심사를 하지 않은 상태에서 성공한 것처럼 서술하지 않습니다.
