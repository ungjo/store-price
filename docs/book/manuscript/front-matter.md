# 머리말

**처음부터 따라 만드는 꼬마 시장 Android 앱**  
VS Code에서 첫 코드를 쓰고 내 Android 기기에 앱을 설치하기까지

사과가 한 개에 1,500원이고 우유가 한 팩에 2,500원이다. 사과 두 개와 우유 한 팩을 골랐다. 만 원짜리 한 장을 내면 얼마를 돌려받을까? 아이가 4,500원이라고 대답하기까지, 앱은 꽤 많은 일을 해야 한다. 사과를 누른 횟수를 기억하고, 상품 개수와 금액을 구분하고, 낼 돈을 고르게 하고, 답이 맞았을 때 영수증을 만든다. 이 책에서는 그 한 번의 장보기를 처음부터 구현한다.

예시는 작지만 개발 과정은 실제다. 상품을 담는 버튼을 만든 날에는 버튼을 눌러 보고, 가격을 서버에서 읽는 날에는 연결이 끊겼을 때도 눌러 본다. 마지막에는 PC의 개발 서버를 종료한다. Android의 앱 목록에서 직접 만든 아이콘을 누르고 장보기를 한 번 더 마치면 책의 목표에 도달한다.

### 이 책을 읽는 순서

처음 개발한다면 1~4장을 차례로 읽는다. 2장에서 편집기와 터미널을 여는 법을 익히고, 3장에서 원 단위 가격을 다룬다. 4장에서 내가 쓴 문장이 기기에 뜨면 첫 번째 관문을 통과한 것이다. 이미 Expo 앱을 실행할 수 있는 독자는 5장부터 시작해도 된다.

5~10장에서는 PC와 기기만 있으면 영수증까지 한 번 완성할 수 있다. 11~16장에서는 그 앱이 읽는 데이터, 통신, 작은 화면과 화면 읽기를 차례로 살핀다. 17~20장은 개발 중의 조작을 반복 검사하고 APK를 만들어 내 기기에 설치하는 과정이다.

1. 실습할 PC에서 **장별 실습 예제 ZIP 받기**를 누른다. **`market-lab.zip`에는 20장 ‘꼬마 시장’ 완성 앱의 소스코드가 들어 있다.** 장별로 꺼내 볼 수 있는 예제는 3~20장이다. 1~2장은 기획과 도구 준비를 다룬다. 상품 이름과 가격만 표로 보려면 **상품 12개 CSV 받기**를 누른다.
2. [2.6절](#ch02-s6)을 따라 ZIP을 풀고 VS Code에서 예제 폴더를 연다. 장별 예제를 꺼내는 명령은 **`start.mjs`가 들어 있는 폴더의 터미널**에서 입력한다.

**완성본부터 보기.** 소스코드를 읽으려면 예제 폴더의 터미널에 `node start.mjs 20`을 입력하고 왼쪽에서 **work → ch20 → apps → mobile → App.tsx**를 연다. 브라우저에서 장보기부터 해 보려면 [부록 C.1](#appC-s1)의 **한 줄 실행**을 따라 한다. 이미 20장 앱 폴더에 패키지를 설치했다면 그 폴더에서 `npm.cmd run web`을 입력한다.

**차례로 따라 하기.** 3장은 계산 예제다. 첫 앱은 [4.2절](#ch04-s2)에서 `node start.mjs 04`로 꺼낸다. [4.3절](#ch04-s3)에서 패키지를 설치하고 [4.4절](#ch04-s4)에서 상품 여섯 개를 확인한다. **다음 장의 참고본을 꺼낼 때마다** 터미널에서 `ls`로 `start.mjs`가 보이는지 확인한 뒤 장 번호를 바꾼다. 부록 C.1에는 4장에서 5장으로 이동하는 예도 있다.

### 화면과 코드 읽는 법

`App.tsx`처럼 표시한 글자는 파일 이름이나 명령이다. 코드 상자에 적힌 명령은 특별히 표시하지 않으면 Git Bash에서 실행한다. 한 줄을 입력하고 출력이 돌아온 뒤 다음 줄로 간다. 개발 서버는 실행하는 동안 터미널을 사용하므로, 추가 명령은 새 터미널에서 실행한다.

그림 설명에 **PC 웹 미리보기**라고 적힌 화면은 같은 React Native 코드를 브라우저로 실행한 결과다. **실기기**라고 적힌 그림은 Android에서 확인한 화면이다. 터미널 결과 발췌는 눈여겨볼 줄만 뽑아 조판했다. 버튼 모양이나 기기 이름이 조금 달라도, 상품 수·총액·기능의 결과를 보고 다음 단계로 넘어갈 수 있다.

예시 상품과 가격은 연습용이다. 상품 이름·단위·가격을 바꿔도 되지만 처음 한 번은 책의 값을 사용하자. 그래야 내 화면에 뜬 5,500원이 계산이 맞아서 나온 값인지 곧바로 확인할 수 있다.
