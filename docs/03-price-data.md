# 3. 이마트 온라인 가격 데이터 확보

조사일: 2026-11-09. 이 문서는 기술 조사와 설계 기록이며, 실제 이용허락을 받았다는 뜻이 아닙니다.

## 확인한 사실

SSG의 공식 EAPI 문서는 존재합니다. 상품등록·주문·배송 등 협력업체의 판매 운영을 위한 API가 안내되어 있습니다. 이번 조사에서는 제3자 어린이 앱이 이마트 전체 상품 가격을 저장·재표시할 수 있는 공개 API 및 이용허락을 확인하지 못했습니다.

- [SSG 공식 API 안내](https://eapi.ssgadm.com/info/notice/noticeInfo.ssg?postngId=1128750463)
- [협력업체 API 문서 사례](https://eapi.ssgadm.com/info/itemQnaAnsApi.ssg)

SSG 고객센터 하단에는 상품·판매자·쇼핑정보 등의 무단 복제·배포·스크래핑 금지 고지가 있습니다. 자동 수집과 앱 재표시, 이미지 사용, 책 수록, GitHub 재배포의 범위를 각각 확인해야 합니다. API 문서나 상품 페이지를 읽을 수 있다는 사실만으로 재배포 권한이 있다고 판단하지 않습니다.

- [고객센터 고지](https://www.ssg.com/customer/main.ssg)
- [SSG 이용약관](https://member.ssg.com/policies/terms.ssg)

온라인과 오프라인, 점포·행사·확인 시점에 따라 가격이 다를 수 있습니다. 이 앱에서는 SSG.COM 이마트 온라인 가격임을 명시하고 오프라인 점포 가격으로 표시하지 않습니다.

[SSG 공식 FAQ](https://www.ssg.com/customer/faqKeywordList.ssg?_mpop=no&keyword=%EB%B0%B0%EC%86%A1%EB%B9%84&page=1)

robots.txt는 조사 도구로 확인하지 못했습니다. 읽지 못한 결과는 허용 또는 금지를 입증하지 않으며, robots.txt 자체도 앱·책·GitHub 재배포 허락을 대신하지 않습니다.

## 개발 중 사용할 데이터

- 첫 개발 단계에는 자체 작성한 상품명과 예시 가격을 사용합니다.
- 모든 예시 화면에서 실제 이마트 가격으로 오인하지 않게 표시합니다.
- 상품 이미지는 자체 제작 또는 별도 사용권이 있는 것부터 사용합니다.
- 실제 가격 공급자는 별도 모듈로 두어 승인된 API·제공 파일 등으로 교체합니다.
- 현재 실제 가격 수집, 데이터 제휴 요청 전송, 실제 상품 DB 적재는 수행하지 않았습니다.

## 가격 이력 설계 초안

| 정보 | 목적 |
| --- | --- |
| product_id / source_product_id | 내부 상품과 출처 상품을 연결 |
| name / package_quantity / package_unit | 상품·규격 구분 |
| price_krw | 원 단위 정수 금액 |
| source_type / source_url | API·파일 등 자료의 출처 |
| sales_channel / store_id | 온라인·점포 구분, 점포 미확인 시 null |
| observed_at | 가격을 확인한 실제 시각 |
| valid_from / valid_until | 행사 유효기간, 관측 시각과 분리 |
| promotion_type / promotion_conditions | 회원·카드·묶음 등 조건 |
| availability | 품절 등 판매 상태 |
| rights_status | 사용 범위 확인 상태 |
| is_sample | 예시와 실제 자료 구분 |

products와 price_observations를 분리하여 가격을 덮어쓰지 않고 이력을 남길 계획입니다. 수집 실패 때 마지막 가격을 오늘의 가격으로 갱신하지 않습니다. 수량·규격·조건이 다른 가격을 같은 값처럼 비교하지 않습니다.

## 데이터 제휴 문의 초안 — 미전송

SSG.COM 이마트 온라인 상품 가격을 활용하는 초등 1~3학년 대상 시장놀이 교육 앱을 개발하고 있습니다.

상품명·규격·가격·확인시각을 저장하고 Android·iOS 앱에 표시할 수 있는 API 또는 제공 파일이 있는지 문의드립니다. 사용 대상은 소수의 생활·식료품이며, 갱신 주기와 저장 기간은 제공 조건에 맞추겠습니다.

아래 범위를 별도로 확인하고 싶습니다.

1. 앱에서 가격과 출처를 표시할 수 있는 범위 및 비용
2. 상품 이미지·상표·상세 설명의 사용 가능 범위
3. 가격 이력 저장·오프라인 캐시·서비스 종료 후 삭제 조건
4. 개발 과정을 책으로 출판할 때 상품 정보·화면을 수록할 수 있는 범위
5. GitHub에는 앱 코드와 자체 예시 데이터를 공개하고 실제 데이터는 제외하는 방식의 허용 여부
6. 담당 부서와 필요한 계약 절차

현재 확인한 문의 출발점은 SSG 고객센터이며, 데이터 제휴 전용 접수처는 확인하지 못했습니다. 실제 발송은 사용자의 명시적 요청 후 진행합니다.
