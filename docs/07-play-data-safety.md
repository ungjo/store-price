# 꼬마 시장의 Google Play 데이터 보안 답변

대상은 Android 패키지 `com.ungjo.storeprice`의 내장 예시 상품 12개 전용 첫 출시판(버전 코드 3)이다. 같은 패키지의 **비공개 테스트·공개 테스트·프로덕션에서 제공하는 모든 버전**이 아래 설명과 일치할 때 적용한다. Google은 내부 테스트 트랙만 사용하는 버전을 데이터 보안 공개 대상에서 제외한다. 따라서 상품 서버를 쓰는 버전 코드 2는 내부 테스트로만 제공하고, 비공개 테스트와 프로덕션에는 새 AAB를 사용한다. [Google Play 데이터 보안 양식 안내](https://support.google.com/googleplay/android-developer/answer/10787469?hl=ko)

## Play Console에 입력할 내용

| 항목 | 선택 또는 입력 | 판단 근거 |
| --- | --- | --- |
| 개인정보처리방침 | [꼬마 시장 개인정보처리방침](https://ungjo.github.io/store-price/privacy/) | 앱 안에서 같은 내용을 읽을 수 있다. |
| 데이터 수집 및 보안에서 필수 사용자 데이터 유형의 수집·공유 여부 | **아니요** | 상품 목록은 앱에 들어 있고 장바구니, 놀이돈, 답, 영수증은 기기 메모리에만 있다. 앱은 로그인, 실제 결제, 광고, 분석 SDK를 사용하지 않는다. |
| 데이터 유형 및 처리 목적 | **선택할 항목 없음** | 놀이 영수증은 실제 구매 내역이 아니다. 앱이 대략적 위치, 기기 식별자, 이용 내역, 이메일을 전송하는 기능도 없다. ‘아니요’ 다음에 생략되는 세부 항목은 입력하지 않는다. |
| 계정 생성 방법을 별도로 묻는 경우 | **앱에서 사용자가 계정을 만들 수 없음** | 회원가입, 소셜 로그인, 외부 가입 링크가 없다. 계정 삭제 URL은 해당하지 않는다. [Google Play 계정 삭제 안내](https://support.google.com/googleplay/android-developer/answer/13327111?hl=ko) |
| 독립 보안 검토 배지를 묻는 경우 | **선택하지 않음** | 출시 검사는 개발팀의 기능·네트워크 검사다. 독립 보안 평가 인증을 받은 기록은 없다. |

제출 전 스토어 등록정보 미리보기에서 **수집하는 데이터 없음**, **제3자와 공유하는 데이터 없음**으로 표시되는지 확인한다. 지원 이메일은 앱에 문의처로 표시된다. 사용자가 앱 밖에서 메일을 보내야 개발자가 발신 주소와 내용을 받는다. 앱에는 문의 폼이나 자동 첨부·전송 기능이 없다. 문의 메일의 사용 목적과 삭제 절차는 방침에서 별도로 설명한다.

## 상품 서버를 제외한 이유

이전 내부 테스트판은 앱을 열자마자 같은 예시 상품을 원격으로 조회했다. 상품명과 가격을 읽기만 해도 서버는 연결을 처리하며 접속 IP와 프로그램 정보, IP 기반 지역 등을 기록할 수 있었다. 어린이만을 대상으로 하는 앱에는 사용하는 API·SDK의 데이터 처리도 포함해 가족 정책이 적용된다. 첫 출시판은 상품을 앱 안에 담아 이 조회 자체를 없앴다. TalkBack 설정 버튼은 Android 접근성 설정을 열고, 앱 안에서 방침을 읽는 동안에도 상품 서버를 사용하지 않는다. [Google Play 가족 정책](https://support.google.com/googleplay/android-developer/answer/9893335?hl=ko)

이 답변은 새 AAB의 패키지 및 권한, 상품 조회 경로, 포함한 SDK, 온라인 기기에서의 실행 결과를 함께 대조해 사용한다. 기존 온라인 버전이 비공개 테스트 등 신고 대상 트랙에 추가되거나 향후 상품 서버, 계정, 오류 보고, 광고 SDK 등을 도입하면 해당 버전까지 포함하여 양식과 방침을 갱신한다.
